# Trilhas

Adicione aqui arquivos `.mp3`, `.wav`, `.m4a`, `.aac`, `.ogg` ou `.flac` cuja licença permita publicação nas redes sociais.

Os arquivos são ordenados pelo nome e escolhidos de forma determinística pelo número do dia. Se a pasta não contiver uma trilha, o FFmpeg gera uma de três ambientações sintéticas originais como fallback. Guarde aqui também uma cópia da licença ou da atribuição exigida para cada música adicionada.
